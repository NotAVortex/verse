Features

What it actually does.

Twelve mechanisms, all real. Click any card for the magic behind it.

nemotron-lightning→nemotron-ultra→flint→ernie→ling→dots

Each hop is tried in order. A provider rate-limiting upstream reads like a busy line: Verse silently re-issues the request to the next model and stitches the stream where it left off. You see a tiny model-label swap, nothing else.

OFFLOWMEDIUMHIGH

The effort value rides the request as reasoning-effort. The visible effect is the thinking trace itself: lower effort, shorter trace, faster first token. OFF skips the trace entirely and answers immediately.

Thought process
  1. Scout: surveying the question
  2. Analyst: structuring the reply
  3. Critic: checking the analogy

Reasoning tokens stream into a frosted drawer while they arrive. When the answer starts, the trace collapses to a one-line pill — open it any time to re-read how the answer was built.

paste / drop→ingest→content part
  • images — base64, inline
  • pdf — text mined from the raw PDF parse, in-browser
  • code & text — inline, capped by size
  • everything else — metadata chip only
hairline frame → click → lightbox, escape to close

Gallery images ride the timeline in framed thumbnails aligned to the message side. The lightbox is a single overlay — no tabs, no gallery chrome.

goal Scout — survey the space Analyst — commit to positions Critic — stress-test the draft one answer

Workers share the goal with distinct system prompts and answer simultaneously. The synthesis merges their output into a single message — you read one document, not three opinions.

your folder→shell-enforced→[read path="…"]

One toggle in Settings. Every read request must name a path inside the granted folder and the desktop shell rejects anything else. Files the AI creates arrive as verse-file blocks — download cards in the chat, written where you said.

deadline: the 15th, not the 1st route keys: quay lock ↔ blue key "— twelve lines about the weather …"

A pin lifts one sentence out of a message and keeps it in context forever. Everything unpinned ages out with the thread — the model remembers what mattered, not what was merely said.

compact →

Every request is metered against the model's real window. As the bar climbs, the oldest turns are summarized and folded away — the thread keeps going where other clients hit a wall.

The desktop shell adds the frameless window, drag regions and the file sandbox. The web build skips those and delivers everything else — chat, agents, traces, memory — from the same static assets.

Setup

How it works, end to end.

Six steps, about two minutes.

  1. 01

    Take your OpenRouter key

    Create one at openrouter.ai. Free models need a key, not a payment method.

  2. 02

    Install, paste the key once

    Run the 115 MB installer, paste the key into Settings. It never leaves local storage.

  3. 03

    Models detect themselves

    The catalog loads and every free model appears in the picker. Zero configuration.

  4. 04

    Talk, paste, drop

    Ask, paste images or code, drop PDFs — all of it enters one continuous thread.

  5. 05

    Grant file access when you want it

    One toggle in Settings. The AI reads only inside the folder you granted, enforced by the shell.

  6. 06

    Nothing leaves but the chat itself

    Keys and transcripts live on your machine. The only traffic is the completion request.
